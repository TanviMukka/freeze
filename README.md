# Time Freeze
Oh, no! Pingu broke his magical pocket watch and froze time!
To get time to be back to normal, Pingu has to find some parts to fix it in, ironically, under a few minutes.

Live Demo: [View Live Project]()
Built By: Tanvi, Niharika

![A screenshot of the starting screen of Time Freeze](res://start_screen.png)

### How to Play
- Read the dialogue which comes at the start of the game to understand the context.
- Find and read the instructions from the desk and the riddle book to figure out the code to unlock the room to get the parts to fix the pocket watch.
- Do all of this in under a few minutes!

If you would like to play this game locally, download the files from GitHub and run it on Godot.

### How We Built It
We built this project completely using Godot. 
Most of the art in this project was designed by Niharika using Piskel.
